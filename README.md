# 💪 Workout Tracker

Progressive Web App для отслеживания тренировок с календарём, дневником и статистикой.

## Возможности

- 📅 Интерактивный календарь с отметками о тренировках
- 📝 Дневник тренировок с заметками, оценками настроения и усталости
- 📊 Статистика тренировок по дням недели
- 💾 Локальное сохранение данных (localStorage)
- 📤 Экспорт данных в JSON
- 📥 Импорт данных из резервной копии
- 📱 Работает как на мобильных, так и на десктопе
- 🔄 Offline-first - работает без интернета

## Быстрый старт

### Локально

Просто откройте `index.html` в браузере.

Или используйте локальный сервер:
```bash
# С Python 3
python -m http.server 8000

# С Python 2
python -m SimpleHTTPServer 8000

# С Node.js
npx http-server
```

Затем откройте http://localhost:8000

### Развертывание на Vercel

1. **Создайте GitHub репозиторий**
   - Перейдите на https://github.com/new
   - Создайте новый репозиторий (например, `workout-tracker`)
   - Скопируйте SSH или HTTPS URL

2. **Отправьте код на GitHub**
   ```bash
   git config user.email "your-email@example.com"
   git config user.name "Your Name"
   git add .
   git commit -m "Initial commit: workout tracker app"
   git branch -M main
   git remote add origin <YOUR_GITHUB_URL>
   git push -u origin main
   ```

3. **Подключите к Vercel**
   - Перейдите на https://vercel.com
   - Нажмите "New Project"
   - Выберите ваш GitHub репозиторий `workout-tracker`
   - Нажмите "Deploy"
   - Готово! Приложение будет доступно на URL типа `https://workout-tracker-xyz.vercel.app`

## Как использовать

### Календарь
- Нажимайте на дни в календаре для отметки тренировок
- Выбирайте тип тренировки из графика
- Завершенные тренировки отмечаются синим

### Дневник
- Добавляйте заметки о тренировке
- Оценивайте настроение и усталость
- Удаляйте записи по необходимости

### Экспорт/Импорт
- Используйте "Экспорт" чтобы сохранить все данные в JSON
- Используйте "Импорт" чтобы восстановить данные на другом устройстве

### Настройки
- Добавляйте свой график тренировок
- Выбирайте типы тренировок (ноги, спина, грудь и т.д.)

## Хранение данных

Все данные хранятся локально в браузере (localStorage). Никакие данные не отправляются на серверы.

Чтобы не потерять данные:
1. Регулярно делайте экспорт
2. Сохраняйте JSON файлы в безопасном месте
3. При переходе на новое устройство используйте импорт

## Технологии

- HTML5 + CSS3
- Vanilla JavaScript (без зависимостей)
- LocalStorage API
- Service Workers (для оффлайн режима)
- Progressive Web App (PWA)
